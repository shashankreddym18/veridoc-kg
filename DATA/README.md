# DATA

- `raw/Insurance/` : the seven course-provided files (six PDFs and `WS-sample-deduction-file.xls`).
  Not committed. Download "Small Data: Insurance PDFs" from the Canvas guidance page and unzip here.
- `gold/fields_gold_draft.json` : field labels, first pass (50 items: 32 values, 18 fields that must stay empty).
- `gold/qa_gold_draft.json` : question set (31 questions: 22 single-fact, 5 multi-hop, 4 unanswerable).
- `synthetic/<dev|test>/gold.json` : known values of the synthetic filled forms. The PDFs are regenerated
  with `python -m veridoc.synthetic --set dev|test` (fixed seeds), so they are not committed.
- `processed/` : generated by the pipeline (page JSON, facts, graph, deduction file). Not committed.

- `gold/text/<doc_id>_p<NNN>.txt` : transcriptions of scanned pages, typed from the page image in reading
  order (rows left to right), redacted values left out. Two pages (certificate p1 and p5), each checked
  against the PDF by a second person.
- `gold/fields_gold_second.json` : the second, blind annotation pass (made with `python CODE/app/annotate.py`; E11).
- `gold/qa_human.json` : 29 of the questions in a second team member's own words (`python CODE/app/reword.py`);
  answers and evidence pages unchanged.
